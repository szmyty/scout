# Scout Pillars

- **Discovery:** search broadly across countries, institutions, and role families.
- **Verification:** resolve leads to authoritative vacancy facts.
- **Evaluation:** apply hard gates, CareerEV/PursuitEV, confidence, and qualitative fit.
- **Queueing:** convert research into a bounded set of next actions.
- **Privacy-safe projection:** keep private application state in `szmyty/career`.
- **Continuity:** persist enough context to resume across chats, models, and providers.
