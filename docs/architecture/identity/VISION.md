# Scout Vision

Scout should become a reusable, provider-independent career opportunity intelligence layer.

The long-term system can automate discovery, deduplication, verification, scoring, expiry detection, and public-safe reporting while keeping consequential application decisions human-governed.

The present implementation deliberately permits a simpler shortcut: ChatGPT or another research agent performs live scans, records evidence, and updates the reviewed queue. The architecture preserves a path to later automation without requiring that automation now.
