# Scout Methodology

For each scan: define countries and lanes; search employer ecosystems and broad indexes; deduplicate; re-open authoritative postings; record deadline/location/employment/language/eligibility/sustainability signals; apply hard gates; score with PursuitEV; record confidence and unknowns; human-select a bounded queue; hand selected roles to Career; reverify before application; publish only a reviewed public-safe projection.

`docs/PURSUIT-EV.md` owns the versioned formulas.
