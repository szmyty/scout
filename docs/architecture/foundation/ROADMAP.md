# Scout Roadmap

## Now
Stabilize the dashboard/privacy boundary, maintain the international queue, use PursuitEV consistently, and keep handoff context current.

## Next
Add repeatable scan snapshots, stale-role checks, stronger provenance/confidence display, and privacy-safe aggregate metrics.

## Later
Optional automated discovery adapters, vacancy reverification, notifications, and provider-independent research-agent orchestration.

Automation is not required for the current job-search mission.
