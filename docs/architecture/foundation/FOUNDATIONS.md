# Scout Foundations

1. Career discovery is a continuously changing data problem.
2. Verification is separate from discovery.
3. Evaluation is separate from employer-facing application material.
4. Private context is never required by the public runtime.
5. Every score is versioned and evidence-qualified.
6. The system remains useful when operated manually through an AI assistant.

The current static site is a delivery choice, not the logical architecture.
