# Scout System

```text
search surfaces
  -> candidate discovery
  -> deduplication
  -> official-source verification
  -> structured evidence
  -> hard gates
  -> CareerEV / PursuitEV
  -> human review
  -> private Career record
  -> reviewed public projection
  -> Scout dashboard
```

The public repository stores only reviewed public data, static UI assets, validation/build scripts, and public methodology. Discovery providers, verification adapters, scoring, expiry checks, and export generation are future automation seams.
