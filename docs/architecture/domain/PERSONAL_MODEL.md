# Scout Operator Model

Scout assumes the person conducting the search has finite time, attention, and interview energy. The system favors bounded queues, sustainable roles, explicit pursuit cost, reusable evidence, low-friction handoffs, and enough personal-life compatibility to preserve long-term independent work.

Sensitive personal details are intentionally excluded from this public repository. Private constraints belong in Career.
