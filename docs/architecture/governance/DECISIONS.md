# Scout Architecture Decisions

Accepted baseline: Scout remains public; Career remains private source of truth; Scout receives only sanitized exports; private reasoning/materials never enter Scout; PursuitEV is a versioned aid rather than prediction engine; official employer sources own live vacancy facts; AI-assisted scanning is an acceptable current execution layer; application submission remains human-authorized; architecture documents are the durable context layer across chats/providers.

Future material changes should be captured as ADRs and reflected here.
