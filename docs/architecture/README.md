# Scout Architecture Corpus

Scout follows the 18-concern Aether architecture model.

- `identity/`: PURPOSE, VISION, PRINCIPLES, PILLARS, MANIFESTO
- `meta/`: EPISTEMOLOGY, AI_CONSTITUTION, META
- `domain/`: ONTOLOGY, PERSONAL_MODEL (public operator model only)
- `foundation/`: FOUNDATIONS, SYSTEM, ARCHITECTURE, METHODOLOGY, ROADMAP
- `experience/`: DESIGN, DESIGN_SYSTEM
- `governance/`: DECISIONS

Start with `../../ARCHITECTURE.md` for the repository-level entry point. Read `../PURSUIT-EV.md` for the versioned scoring model.
