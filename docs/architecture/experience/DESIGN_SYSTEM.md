# Scout Design System

Use consistent semantics for status, freshness, confidence, priority, and privacy. Status includes discovered, verifying, ready, submitted, watching, and closed. Freshness always exposes verification time or stale state. Confidence is high/medium/low and remains separate from score.

Accessibility, keyboard use, readable contrast, reduced motion, and responsive layouts are baseline requirements.
