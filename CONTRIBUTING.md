# Contributing

Scout is a personal operational dashboard with a strict privacy boundary.

Before proposing a change:

1. Read "AGENTS.md".
2. Keep data changes within the documented public contract.
3. Run "python3 scripts/validate.py".
4. Run "python3 scripts/build.py".
5. Inspect the generated inventory and complete diff.

Do not submit personal data, private application materials, recruiter correspondence, or speculative claims about an employer.
